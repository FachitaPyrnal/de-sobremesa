# TP Final — Aplicación Multisitio con Angular

**Alumno:** Iván Szpyrnal  
**Proyecto:** De sobremesa — Recetas para compartir

**Link a entregar:** https://github.com/FachitaPyrnal/de-sobremesa

**Demo:** https://fachitapyrnal.github.io/de-sobremesa/

Aplicación Angular que permite explorar recetas de TheMealDB, buscar por nombre, filtrar por categoría, consultar ingredientes y pasos mediante una ruta dinámica y guardar favoritos. Incluye inicio, dos páginas estáticas, listado, detalle por ID, página 404 y estilos propios responsive.

Las instrucciones de instalación, la documentación de la API, el mapa de rutas y la correspondencia con los requisitos están en `README.md`.
